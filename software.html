Web-Konfigurator, Flasher & Sync

Reaktive Browser-Toolchain mit nativer Web Serial USB-Schnittstelle. Ermöglicht das bidirektionale Auslesen und Schreiben der Konfiguration (EEPROM-Sync), das direkte Flashen von Firmware (.hex / .bin via STK500v1) im Browser und den Export von maschinenspezifischen C++ config.h Headern.
